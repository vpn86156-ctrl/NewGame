# TERRA Летопись

Интерактивный фанатский спутник по Terraria на React + Vite.

## Открыть сайт

**[Запустить TERRA Летопись](https://htmlpreview.github.io/?https://raw.githubusercontent.com/vpn86156-ctrl/NewGame/arena/78062b9a-newgame/docs/index.html)**

Опубликованная статическая версия находится в папке `docs` этой ветки.

## Возможности

- последовательный путь мира с подтверждением пройденных этапов;
- режим без спойлеров для будущих глав, историй и рецептов;
- подбор доступных крафтов по ресурсам в рюкзаке;
- библиотека рецептов и маршруты получения находок;
- истории Гида с практическими подсказками;
- личный дневник приключений и случайные задания;
- строительный челлендж, избранное и глобальный поиск (`Ctrl/Cmd + K`);
- вступительная сцена с Лунным лордом и анимации карточек при прокрутке;
- сохранение прогресса и настроек в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Проект является неофициальным фанатским концептом. Terraria и права на игровую вселенную принадлежат Re-Logic.

# TERRA Летопись

Интерактивный фанатский спутник по Terraria на React + Vite.

## Открыть сайт

**[Запустить TERRA Летопись](https://htmlpreview.github.io/?https://raw.githubusercontent.com/vpn86156-ctrl/NewGame/arena/78062b9a-newgame/docs/index.html)**

Опубликованная статическая версия находится в папке `docs` этой ветки.

## Возможности

- последовательный путь мира с подтверждением пройденных этапов;
- режим без спойлеров для будущих глав, историй и рецептов;
- **все 3 655 рецептов Terraria 1.4.5** и 3 233 создаваемых предмета, с пагинацией, фильтрами и вариантами крафта;
- оригинальные игровые спрайты предметов и GIF-анимации ключевых боссов;
- подбор доступных крафтов по ресурсам в рюкзаке, включая поиск и добавление любого ингредиента;
- маршруты получения находок с настоящими игровыми иконками;
- истории Гида с практическими подсказками;
- личный дневник приключений и случайные задания;
- строительный челлендж, избранное и глобальный поиск (`Ctrl/Cmd + K`);
- вступительная сцена с Лунным лордом и анимации карточек при прокрутке;
- сохранение прогресса и настроек в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Данные и лицензии

Полный каталог и атласы спрайтов адаптированы из [Doeschi/Terraria-Progress-Tracker](https://github.com/Doeschi/Terraria-Progress-Tracker) на основе [Official Terraria Wiki](https://terraria.wiki.gg/). Снимок данных: Terraria 1.4.5, 2026-10-08. Данные и игровые иконки распространяются по [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/); компактная адаптация в `src/data/full-catalog.json` использует те же условия. Анимации боссов получены с Official Terraria Wiki.

Проект является неофициальным некоммерческим фанатским концептом. Terraria и права на игровую вселенную принадлежат Re-Logic.

# TERRA Летопись

Интерактивный русскоязычный спутник по Terraria на React + Vite.

## Открыть сайт

**[Запустить TERRA Летопись](https://htmlpreview.github.io/?https://raw.githubusercontent.com/vpn86156-ctrl/NewGame/arena/78062b9a-newgame/docs/index.html)**

Опубликованная статическая версия находится в папке `docs` этой ветки.

## Полная офлайн-версия

Кнопка **«Офлайн»** в верхней панели открывает скачивание `TERRA-Offline.zip` и резервное копирование.

1. Скачайте и полностью распакуйте архив.
2. Откройте `index.html` двойным кликом.
3. Интернет, Node.js, Python и локальный сервер не нужны.

В архиве находятся приложение, полный каталог, спрайты, GIF, шрифты и русские
описания. Работают крафты, деревья рецептов, поиск, источники, NPC, рюкзак,
прохождение и дневник. Только внешние ссылки Wiki требуют сети.

**«Экспорт JSON»** сохраняет инвентарь, прогресс, избранное и дневник. Перед
переносом или обновлением экспортируйте файл, а затем выберите его через
**«Импорт JSON»**. Импорт показывает состав копии и требует подтверждения.

Онлайн-сборка также содержит PWA-манифест и service worker с полным предварительным
кэшем приложения. Установка зависит от браузера и хостинга; HTML Preview может её
не поддерживать, поэтому переносимый ZIP остаётся основным офлайн-вариантом.

## Возможности

- **6 186 предметов и все 3 655 рецептов Terraria 1.4.5**, включая варианты крафта;
- интерактивные деревья рецептов: вложенные ветви, количество с учётом выхода,
  выбор вариантов, рюкзак и переходы к источникам;
- поиск по-русски и по-английски, с опечатками, транслитерацией и синонимами;
- фильтры по этапу, биому, классу оружия, версии и платформе;
- оригинальные игровые спрайты предметов, NPC и GIF-анимации боссов;
- подбор доступных крафтов по любым предметам в рюкзаке;
- источники получения с шансами, условиями и русскими маршрутами для особых способов;
- 26 городских NPC с предпочтениями и бонусами + 14 других существ;
- последовательный путь мира и режим без спойлеров;
- истории Гида, личный дневник, задания, челлендж и избранное;
- полностью автономная работа и переносимые JSON-сохранения.

## Запуск из исходников

```bash
npm install
npm run dev
```

Полная production-сборка (онлайн + ZIP + service worker):

```bash
npm run build
npm run preview
```

Отдельно пересобрать только переносимый архив:

```bash
npm run build:offline
```

Результат появится в `public/downloads/TERRA-Offline.zip` и будет включён в
следующую онлайн-сборку. Для публикации через относительные пути используется
`GITHUB_ACTIONS=true npm run build`.
